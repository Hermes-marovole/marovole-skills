# 平台热门账号/赛道调研（「抖音/视频号最近什么 AI 内容火、哪些账号」）

用户问的是一个平台的整体格局而不是某个账号时用。产出：按赛道分组的账号清单 + 每条结论的可信度标注，再接账号级拆解（douyin-account-teardown.md）。
用户说「借鉴抖音爆款重新做选题策划」「按整个赛道重做起号方案」→ 走下面的**赛道基准库**，产出是量化对标表 + 选题清单，不是账号名单。

## 数据源（按可信度）
1. **自己抓的搜索接口原数据（最高）**：抖音网页搜索按关键词批量抓 100-200 条，每条带作者粉丝数、赞/藏/转/评、时长、画幅、发布时间。见下「赛道基准库」。
2. **新榜「涨粉周榜」**（抖音/B站/快手，每周一期，newrank.cn 文章或腾讯新闻转载）：有账号名、一周涨粉、账号类型说明。**不含视频号**。
3. **DataEye 月度「AI剧漫剧百强榜」**（澎湃号转载）：抖音/红果 AI 剧、漫剧的播放增量、出品方，月初发布上月。
4. 新榜/36氪/21经济网半年或月度盘点：AI 原生创作者涨粉清单、赛道分类。
5. 平台官方活动页/创作者大会报道：扶持标签（#ai新星计划 等）。
- 每个账号数字须来自本次打开的原文；个人专栏（知乎等）列出的账号和数字，搜不到第二个独立来源就标「未核实」，不进结论。
- 半年盘点里的数字是上半年累计，不是「最近」，写清统计区间。
- 二手榜单只给「谁火了」，不给「什么结构的片子火」。做选题策划必须自己抓数，别拿榜单转述当依据。

## 核实第三方爆款数据表（「这些数据是否真实」）
1. **逐条搜标题**（ego-browser 一个 TaskSpace）：`goto(/search/<标题关键词>?type=video)`（goto 包 try），`waitForFunction` 等 `a[href*="/video/"]` 出现 >3 个，再在页面里取每个视频链接所在 `LI` 卡片的 innerText——卡片文本含「时长 赞数 标题+话题 @作者 N天前」，足够判断是不是同一条。标题去掉标点、截成 8-12 字的关键词比整句好搜。
2. **进视频页取粉丝和精确时间**：`/video/<id>` 的 innerText 用正则抓 `粉丝\s*[\d.]+万?`、`发布时间[：:]\s*[\d\-: ]+`、`获赞\s*[\d.]+万?`（获赞是作者总赞，单条赞看搜索卡片或 detail）。
3. **判定口径**：当前数比表里略高（几天自然增长）= 吻合；表里「倍数」先反算公式（常见 = 单条赞 ÷ 粉丝）再核。发布日差 1 天属工具口径误差，写出来但不算造假。
4. **搜不到 ≠ 假**：换「vibe知识大赏 + 关键词」、加 `&publish_time=7` 再搜一轮，仍无就标「未核实（搜索未命中）」并请用户给链接或作者名，不下「伪造」结论。
5. 补一条提醒：倍数用的是**当前**粉丝，爆款本身会带粉，所以倍数偏高；但「千粉号单条十几万赞」这一结论不受影响。

## 赛道基准库（做选题策划时）
目标：把「对标哪个爆款」变成一张可比较的表，再用它反推选题。

1. **批量抓**（ego-browser 一个 TaskSpace）：页面 `Network.enable` → `page.events()` 清缓冲 → 依次 `goto(/search/<词>?type=general)` 等 ~9s → 收集 URL 含 `search` 的响应体，全部落一个 `search_raw.json`（每行一条响应原文）。多换 3-4 个词（活动标签、赛道词、话题词），去重后通常 150-200 条。
2. **聚合**（execute_code 用 stdlib，沙箱**没有 numpy**，中位数/分位数自己写）：从每条 `aweme_info` 取 `statistics.*`、`author.follower_count`、`video.duration`(ms)、`video.width/height`、`create_time`。算：赞中位/P75/P90、≥10 万条数、**转/赞**、藏/赞、横竖、时长分桶（<60 / 60-100 / 100-140 / 140-200 / 200-400）。
3. **先洗文本再分类**：`re.sub(r'#[^#\s]{1,20}','',desc)` 去掉话题标签再按主题归桶。不洗就直接做关键词分类会得出反的结论——活动标签（`#ai新星计划`、`#vibecoding`）会让 90% 的片子都命中「AI」这一桶。分类后按桶报「条数 / 赞中位 / ≥10 万条数」，中位数比均值稳（头部单条会把均值拉飞）。
4. **读出四件事**：
   - **粉丝门槛**：筛 `fans<=3万 且 likes>=10万` 的子集。这批片子存在，就说明平台按内容分发、粉丝量不是起号门槛；表里连粉丝数一起列，比任何励志结论都硬。
   - **哪个桶值钱**：比较各主题桶的赞中位数。心理/认知类通常显著高于工具/AI 题材类——这类差 5-10 倍时，选题就该往共鸣走，AI 退到「由某模型制作」的元信息里。
   - **画幅与时长的真实分布**：数横竖条数、按桶算时长中位。头部以哪种为主就按哪种做；少数派里有头部时，只能说「两边都出过头部，要实测」，别把少数派写成规律。
   - **转发信号**：转/赞 ≥0.45 = 「这说的就是我」型，是起号最该抄的；<0.15 多是奇观型（收藏高、传播弱）。
5. **结构逆推**：把头部和粉丝<3 万的爆款逐条看标题+时长，写成固定的骨架（钩子句类型 → 机制+数字 → 一个身体感意象撑全片 → 结尾动作/宽慰），再给标题公式。选题清单里每题都要写「对标哪条（赞数）」和「源论文核实状态」。
6. **同名/同题先查占用**：在基准库里 grep 候选选题的关键词，看头部账号是否已做过同一题；做过就换角度或标「已被占，需差异化」。

## 视频号
- 没有公开网页榜单。视频号助手只有本账号数据，无全站榜、无热点入口。
- 全站榜在新榜「新视」(xs.newrank.cn)，需微信扫码登录：让用户扫码后再进；不替用户登录第三方账号。
- 搜狗微信搜索（weixin.sogou.com，ego-browser 可直接打开，不带 tsn 参数）返回的是公众号文章，视频号相关多为过期教程和自述案例，只能当线索不能当数据。
- 查不到就如实写「视频号无可核实账号」，再给用户两条路：扫码进新视 / 用户在微信里搜关键词报账号名由我核实。不要拿教程文章里的案例号凑数。

## 抖音账号搜索卡片的坑
- 搜索结果卡片 innerText 把「抖音号」与「获赞」数字连在一起（如 `dianzihomo148.1万获赞`），分不清哪位属于 ID。以主页 innerText/profile 接口的 `unique_id`、`total_favorited` 为准。

## 排期结论（基准库能直接回答的）
- 同时段涌入量：按 `create_time` 算每天的条数。单日新片越多，同日多发越是自己跟自己抢同一个推荐池；起号期用「一天一条打穿」而不是一天多档，多档只适合已有稳定分发的老号。
- 系列化是标配：同一账号连做 2-3 条同主题（专注力/操控/神话/话术）能吃到二次分发，第一条就成了系列的入口。
