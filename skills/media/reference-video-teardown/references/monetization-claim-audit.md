# 「这个号躺赚」类案例的变现链路真伪审计

触发：用户贴来一条推文/帖文，宣称某人靠某号「零成本躺赚」，要你调研/拆解这个案例。默认假设**发帖人在卖东西**（课程、社群、模板包），先用 3 分钟把它的变现链路拆开，再决定要不要照着拆内容。

## 1. 先看链接参数：一步区分「达人联盟」和「品牌自投」
Amazon 站外链接只有两类，参数长得很像但含义完全不同：

| 参数形状 | 实质 | 谁在赚 |
|---|---|---|
| `?tag=<associates-id>-20` | Amazon Associates 达人联盟链 | 个人拿 1-10% 佣金 |
| `?maas=maas_adg_<hex>_afap_abs&ref_=aa_maas&tag=maas` | **Amazon Attribution**，品牌备案卖家在广告后台自建的站外归因链 | 品牌主自己，转化回流自家 Listing，另拿 Brand Referral Bonus |

`maas_adg_` 只能在 Brand Registry 卖家的后台生成。看到这一串，「普通人挂联盟链躺赚」的说法当场证伪：这是**品牌方的自有获客矩阵号**，有库存、有 FBA 店铺、有投流预算。报告里要把「定性错误」这四个字写出来，并附完整链接，别只写域名。

同理，其它平台的判断口径：`utm_source` 指向品牌自有分析工具 = 自投；`?ref=` + 短链服务 = 联盟；带 affiliate 平台域名（impact/awin/cj）的跳转链 = 联盟。**链接是全篇最便宜的证伪工具，永远第一个看。**

## 2. 卖方主体穿透（ASIN → 人 → 关联公司）
链路：Amazon 商品页 → Seller 名与 Seller ID（`A1U71ODS9RPGJV` 这类）→ 州工商登记搜索（美国常用 Sunbiz/佛州、Delaware Division of Corporations、加州 SOS）→ 登记文件里的 officer/registered agent/地址 → 拿这个地址反查其它公司。

- 商品页要抄全：上架日期（`Date First Available`）、评价数与星级、`N+ bought in past month`、价格与规格份数。
- 工商档案里「唯一高管 + 办公地址与另一家已知大卖同址」是最有力的关联证据；把两家公司的地址原文并排写进报告。
- 人名要落到可核验的履历（前公司、职位），但只写档案/公开页面里能读到的；查不到就写「未核实」，不要靠姓氏推测族裔。

## 3. 反推真实销量，别信播放量
平台只给分桶（`100+ bought in past month` = 100-199 单/月，全渠道合计）。用它当上限，乘单价得月 GMV 区间，再倒推：

- 该号历史总播放 × 主页点击率（冷流量按 1% 上限）× 高客单价站外转化率（$50+ 按 2% 上限）= 这个号全生命周期的订单上限。把算式写出来给区间，不要给一个点估计。
- 如果按达人 3-4% 佣金算，结果只有几十到一百美元级，那就明确写：「即便数字全部为真，这个号的佣金也不足以覆盖人力」，再补一句品牌方为什么还可能干（毛利 + 复购 + 平台返点 + 当作 A/B 测试费）。
- **弃号是结论的强证据**：停更时间点 + 停更前几条的播放塌陷，比任何「据说很赚」都更能说明商业模型跑不通。

## 4. 审计发帖人动机（写进报告第一节）
查发帖人主页外链卖什么、价格多少、卖点是不是「复制这个号」。把「他的数字是截图，且截图停在爆款那两天」写清楚——这不是人身攻击，是让用户知道该信哪几个数。

## 5. 报告口径
- 结论先行：一句话说清「这是谁在运营、赚不赚钱、能不能抄」。
- 宣称 vs 事实两列表，逐条判定（属实 / 截图滞后 / 定性错误 / 严重失实），每条附一手证据出处。
- 区分「不能学的」和「值得学的」：造假人设卖健康品、泛同情起号再硬转高客单——列死坑；对方真正有效的选题钩子与文案结构——单列可用，并说明怎么嫁接到自家账号。
- 不写「疑似」「可能违法」这类定性指控；只说参数归谁、档案写什么、销量标签是多少。
