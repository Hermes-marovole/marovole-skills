# 方法论口播片拆解（对标片本身在「教人怎么做内容/怎么做事」）

对标片的内容就是做法本身（怎么提高完播率、怎么写开头、怎么起号、怎么谈价），拆解目的是学**结构与讲法**，不是复刻选题。这类片没有论文可追，第 3-4 步出处核查跳过：片里只有作者自述，没有可核实研究。

产出骨架固定三段：**结构时间码表 + 手法清单（每条带机制）+ 迁移到自家账号的对照表**，末尾给 1-2 个拍板项然后停。

## 1. 先算三个比值再动结论
- 藏÷赞 ≥ 0.6 → 清单收藏型，观众把它当工具存，报告要写「值得留下的是结构密度，不是账号体量」。
- 转÷赞 ≥ 0.3 → 结论可转述（转发的人是在替朋友做决定）。
- 粉丝量对照：万级以下小号拿到千级收藏/转发，说明火的是结构而不是粉丝盘子。

## 2. 先看作者的发布文案，再决定要不要转写
抓 `aweme/detail` 时 `aweme_detail.desc` 就是作者自己贴的发布文案，长片作者的文案常是**整篇论证的浓缩版**（分段、带比喻、带数字，和抖音「章节要点」的时间码一一对得上）。这时不必跑 Whisper：拿 `desc` + `章节要点` + 抽帧三件套即可写成结构表，并在报告开头注明依据——「内容依据：作者发布文案（与口播章节一致）+ 抖音自动章节 + 抽帧；未跑逐字稿」。十几分钟的片能省掉半小时以上。
判断标准：文案是多段论述、能读出论证顺序 → 可直接用；只有标题 + 话题标签 + 几句口号 → 走第 1 步转写。拿不准时切中段 30s 跑 `--model small` 对齐一句，确认文案确实来自口播。
章节切分：抖音视频页 innerText 的「章节要点」直接给段落骨架和时间码，但它是改写成书面语的大纲、也会漏段，引用原话前必须回文案或逐字稿核对。

## 3. 结构表写「做了什么」，不写「说了什么」
逐段只填行为标签，每段标秒数：钩子 → 立信 → 卖关子 → 原理 → 方法 1..N → 总结 → 转化。方法段时长通常均分，转化段占比小但一定单独成段。

## 4. 手法清单（每条一句，必须带机制）
- **一个例子贯穿全片**：所有方法都拿同一个素材演示。观众不用每段重新理解新例子，只看同一个难词被翻译 N 遍——降认知负担的第一招，也是这类片最容易学走的一招。
- **讲哪招就当场用哪招**：讲卖关子时开头先卖关子，讲疑问句时当场问观众一句。观众先被抓住，再听到这招的名字。
- **难概念挂观众已知的锚**：热点人物、平台梗、生活谐音。陌生概念一律挂在已知物上，不挂在定义上。
- **先给结论再解释，结尾复述同一句**（首尾呼应），把「超级简单」这类短结论做成记忆点。
- **立信用具体数字**（自述的完播率、账号数），但报告里标「作者自述，无法验证」。
- **自嘲换亲近**：把自己写成「浅薄的人」，站到观众一侧而不是讲台一侧。
- **转化段换色调**，观众一眼认出广告段，不污染正片可信度。

## 5. 口播片的视觉只看节奏与字卡
- 切点用 `select='gt(scene,0.15)'`：0.05 会因口型微动、背景微光出几百个假切点；0.15 才接近真实剪点。平均每镜秒数 = 时长 ÷ 切点数，正常口播干货片约 2s 一刀。
- 只记四种视觉装置：关键词黄粗大字（插画面中央）、段落转场插卡（换底色/调色小窗 + 旁白字）、举例插平台截图当证据、转化段换色调。美术风格不学。

## 6. 四种开头结构（迁移到自家选题的通用表）
| 结构 | 公式 | AI 号示意 | 营养号示意 |
|---|---|---|---|
| 引出动机 | 不讲概念，讲观众认识的人或事 | 不讲「上下文窗口」，讲「为什么你跟 AI 聊久了它就失忆」 | 不讲「胰岛素抵抗」，讲「为什么吃完饭就犯困」 |
| 极端描述 | 对立 / 极限设置 | 「最贵的模型和最便宜的，差距不在聪明」 | 「同一碗米饭，两种吃法，血糖曲线完全两样」 |
| 反常识 | 用最低门槛讲最高概念 | 「用小学数学讲清楚大模型怎么猜下一个字」 | 「用一个面包讲清楚升糖指数」 |
| 疑问句 | 直接问，再当场让观众体验 | 「你上一次让 AI 写的东西，自己读完了吗？」 | 「你今天早上吃的是什么？」 |

表里的示意见稿只表形式：**事实另行 grounding**，不许直接进成稿。

## 7. 迁移规则（写进报告的「我们怎么做」节）
1. 每期先写「一句话难概念 + 观众已知的锚」，锚找不到不开拍。
2. 一期只用一个例子贯穿所有段落。
3. 前 5 秒不出现专业术语，术语等观众被留住再给。
4. 讲到某种手法，当场用一次。
5. 结尾一句话回到开头那句。
6. **每期唱同一首歌**：这类方法论号真正的护城河不是选题，是「方向定了就不换」。迁移到自家账号 = 主张句、片尾卡、固定收口、合集名四样每期一致，只换题目。追热点能来播放但沉淀不下来（对标原话：「杂技」不是「歌星」）。
7. **首批几期就是探路的飞镖**：每期戳一个不同痛点，发出去看信号，别先要求策划完美。判据是收藏/评论/转发各占播放的比例 + 评论里「我也是」与主动提问的条数，**不是播放量**；播放低而互动正常 = 技法问题，练技法，不推翻方向。
8. 红线：营养号「极端描述」只做对比、不写成效承诺；公司号口径照旧；个人号画面与文案禁品牌名。

## Pitfalls
- **逐字稿的专有名词必错，必须用画面回校**：Whisper 会把学科词听成同音日常词（偏微分→片尾分）、把热点人物听成近音字（姜萍→江萍）。用抽帧读到的屏幕字卡、例子截图核对，并在报告里列「误听 → 正字」映射；不列映射，拍板后写脚本的人会把错词原样抄进去。
- **作者自述的率值不能当基准**：完播率、涨粉、播放量都是自述，报告标「作者自述，无法验证」，不要写进我们自己的选题依据。
- **平台指标口径没查过就别引用**：如「5 秒完播率」的平台定义与行业基准，本次没查官方口径就写「未核实」，不要拿来当自片预期值。
- **体量差决定哪些维度不可迁移**：百万粉的真人横屏十几分钟、靠人脸和直播建信任，老粉基本盘撑得住长时；同样的时长和横屏搬到自己身上直接崩。拆解时把「可迁移（结构、开头、金句、节奏、判据）」与「不可迁移（时长、画幅、露脸、更新频次）」分开写，不然用户会照着做错。
- **只拆方法不拆结论**：拆出来的是开头结构与讲法，不是「按这个做就能爆」。报告末尾的拍板项应指向「拿哪个选题走这套结构」，而不是复述原片观点。
