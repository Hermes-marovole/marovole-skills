# 形式/视觉风格拆解清单（纯配乐动画知识片）

用于"学习这个样例的动画、视觉、配乐"。报告按以下栏目写，写完给 1-2 个拍板项（配乐方案 A/B + 2-3 个首期选题，每个选题配一个能贯穿全片的视觉隐喻）。

## 必拆栏目
1. 数据：四项计数、发布时长、作者粉丝；分享/赞、收藏/赞比例。
2. 声音：有无人声、曲名（Shazam 多数票）、响度抬升时间点对应哪段。
3. 视觉语言：底色色值、主角元素（线/点/粒子/图形）、唯一强调色及其语义（如红色只给负面词）、字体（衬线/无衬线）、字幕位置与出场动效（blur-in 等）、出处小字位置。
4. 镜头节奏：时长 ÷ 画面数 ≈ 每镜秒数；镜间是硬切还是同一元素连续变形。
5. 结构：按时间段列"画面动作 + 屏幕字"，标出钩子、反转点、数据托底段、收尾金句。
6. 可学 N 条：抽象成规则（一个隐喻贯穿到底、元素越少越高级、数据都转成图形动作、每屏 ≤20 字、结尾可截图金句 + 文案开放问题）。
7. 和我们已有同系列片的差别（查 `~/HermesWork/抖音科普视频/` 下同系列目录的 事实与发布.md，以及 `_research/全平台数据报告-*.md` 里自家同系列的赞/完播）。

## 批量模式（一次拆 5-10 条对标，找共性）
- 目录：`~/HermesWork/抖音科普视频/_research/<主题>-top<N>-<MMDD>/`，抓取按 SKILL.md 第 1 步多条循环。
- 每条一张 24 帧拼图，不管片长：`step=dur/24` → `ffmpeg -vf "fps=1/$step,scale=320:-1" fr_<id>/f_%03d.jpg` → `tile=6x4`。13s 和 146s 的片子都能一图看完结构；拼图逐张交给 vision 读画面字和隐喻。
- 切点计数用 `scene>0.1` 只做粗分型：0 = 同一画面连续变形（长镜/生成动画），几十上百 = MV 式快剪。
- 人声探测批量做：每条切 3-28s 跑 `whisper --model small`，输出是「字幕by…」/外文歌词/孤字 = 无口播；连贯中文叙述句 = 口播。
- 汇总表固定列：题 / 作者·粉丝 / 赞 / 转÷赞 / 藏÷赞 / 时长 / 画幅 / 声音。再写一张「共性 vs 我们现行做法」对照表（画幅、时长、声音、自家同系列数据）——差距表比逐条描述更能让用户拍板。
- 结尾给的选题：每题写清贯穿隐喻 + 计数器怎么设计 + 结尾金句/动作，并标「事实未核实，拍板后再 grounding」。

## 已验证的爆款共性（vibe知识大赏小号爆款，粉丝千级拿 7-45 万赞）
- 画幅几乎全是横屏 16:9（1920×1080），时长 13-90s 为主；超过 2 分钟的极少成小号爆款。
- 无口播：纯配乐、热门歌、或把素材音本身做成旋律（各国「妈妈」发音拼成《小星星》）。唯一带口播的历史长片转/赞最低（≈0.10）。
- 一个隐喻贯穿：血条=感情、N 个圆画出字、AI 接力传话、地图逐点点亮。
- **计数器当骨架**：「第 N 棒」「N 个圆」「音符逐个点亮」——观众看得到进度，完播高。
- 只放一个可核实硬事实托底（Gottman 5:1、傅里叶、m+a 最省力音节），不堆知识。
- 结尾 = 可截图金句 + 情感动作或开放问题（给妈妈打个电话 / 你在转哪个圆），转/赞可达 0.4-0.6。
- 反套路自嘲（「你以为这是知识视频，其实只是木偶跳舞」）26s 也能转/赞 >1。
- 制作方式写进文案（「DeepSeek+Claude 做的」）是卖点。

## 抖音图文/实况（一条笔记 = 多段无声短片 + 一条独立 BGM）
用户贴「一个视频」链接，但页面 SSR 脚本里出现**多条** `douyinvod.com` 视频直链时，这条笔记其实是图文轮播/实况：N 段各自独立的短片 + 一条独立配乐 mp3，不是一条连续正片。
- **判型**：逐段 `ffprobe -show_entries format=duration`，若各段时长之和明显小于配乐时长（例：3.6 + 3.0 + 2.6 = 9.2s，BGM 21.2s），就是图文多段。此时「每镜几秒」直接来自各段时长，不用再跑切点检测。
- **下载**：抓页面时就把 SSR 脚本里的直链 JSON 存下来（直链带签名，事后重拼拿不到）；同一 UA + `-e https://www.douyin.com/` 逐条 curl 成 `clip_N.mp4` 与 `music.mp3`。
- **有声无声**：短片自带 aac 轨不代表有声音，跑 `ffmpeg -af volumedetect -f null -` 看 `max_volume` 再下结论；图文段通常全静音，声音都在那条 BGM 里（所以复刻时按「无声画面 + 用户自挂原声」规划）。
- **拆解**：每段抽首/中/尾三帧，按「行 = 段、列 = 首中尾」拼 `tile=3xN` 联系表，一次交给 vision 读人物/服化道/光线/运镜；段数少时这张表本身就是分镜表。
- **复刻**：段数 = 镜头数，交 `ai-story-video-director` Step 3b；画幅按原片（如 540×720 = 3:4）换算到出片规格，不要硬套 9:16。

## 高燃卡点混剪（Beat-Sync Mashup）拆解与复刻方案
用于拆解和制作影视/科技名场面高燃混剪（典型如歌舞剧/群像卡点混剪，30–40s 内 40–60 镜，中位镜长 0.5–0.6s）：

1. **逐镜中点联系表（替代固定间隔抽帧）**
   - 快剪片用固定秒数抽帧会漏掉 0.4s 短镜或刚好抽在转场模糊帧上。先用 `select='gt(scene,0.2)'` 拿到切点序列 `times`，过滤 `<0.15s` 的闪白帧后，对每个镜头取中点 `mid = (t[i] + t[i+1]) / 2` 抽 1 帧，再用 `tile=7x7` 拼成一张全片逐镜分镜表交由 vision 识别。
2. **鼓点咬合度（Beat-Sync Accuracy）量化测量**
   - 提取 22050Hz 单声道 WAV，用 `numpy` 算 20ms 窗（10ms 步长）RMS 短时能量的正向一阶差分 `np.maximum(0, np.diff(rms))`，取局部极大值且 `>85%` 分位点作为音频瞬态峰值（Onset Peaks）。
   - 计算每个视觉切点到最近音频峰值的绝对距离：统计 `≤50ms`（1.5 帧内）、`≤80ms`（2.4 帧内）占比及中位误差（ms）。顶级混剪中位误差约 30–35ms（1 帧），85%+ 切点落在 80ms 内。
3. **视觉顺接与节奏结构必拆 4 要素**
   - **快慢呼吸波（Pacing Wave）**：前奏铺垫（1–1.5s/镜）→ 主副歌高频连切（0.4–0.6s/镜，死咬每拍/半拍）→ 唱段/金句呼吸段（0.8–2.0s/镜）。
   - **跨片同构动作顺接（Visual Match Cuts）**：按动作母题分组连切（如：连续 5 镜不同人物弹琴手势 → A/B 两片双人对称舞步来回交替 4 轮 → 连续群舞中心旋转 → 连续托举旋转 → 结尾双人特写左右拼屏）。
   - **围绕动作峰值裁切（Action-Peak Trimming）**：0.5s 短镜不能从动作起势切入；用光流/帧差定位源镜头内运动速度最大的爆发帧 $t_{\text{peak}}$，按 $[t_{\text{peak}} - 0.3D, \, t_{\text{peak}} + 0.7D]$ 截取，保证切入瞬间即是动作高潮。
   - **杂志感动态排印（Editorial Kinetic Typography）**：在长镜或唱段衔接处，用粗无衬线 + 衬线斜体（如 `Cormorant-Italic`）+ 装饰符号（`//`、`*`、`~`）做局部叠层，按 Whisper `word_timestamps` 音节级时间戳逐词卡点蹦出。
4. **给用户的 3 套落地方案模板**
   - **方案 A（全自动/半自动成片管线）**：音频 Onset/词级时间戳提取（`beat_grid.json`）→ 源素材切镜 + 光流 $t_{\text{peak}}$ 定位 + 视觉母题打标 → 节拍锁死裁切 + `render2.mjs` 透明底动态字卡合成。
   - **方案 B（剪映专业版 `draft_content.json` 草稿生成）**：脚本完成鼓点检测、素材按动作峰值对齐入出点、动态字卡排布，导出剪映本地草稿目录，供用户在剪映 GUI 里做最后 5 分钟预览与微调。
   - **方案 C（降维移植到自有科普/科技视频）**：在 `_pipeline` 模板中引入 120+ BPM 鼓点网格、前 8 秒 0.47s 高频同构图形/录屏 Match Cut，以及 `//` `*` 混排逐词砸字。
