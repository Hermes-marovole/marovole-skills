# 「这个视频是怎么做的」：代码渲染 / 程序化动画类片子的技法拆解

用户贴一条炫技动画帖（多为 X，也可能是抖音/B站搬运）问「调研一下这个是怎么做的」。这类片的答案不在分镜里，在**作者开源的 Agent Skill / 仓库**里：能拿到源码就读源码，拿不到才回到抽帧推断。交付是「一句话定性 + 制作链路分步 + 抽帧实测 + 复现入口」，不是搬运作者的宣传语。

先判一件事，它决定整篇报告的写法：**是一键直出的（prompt → 成片）还是人带着模型迭代出来的**。用户在意的就是这个差别。判据：作者回复里给出的耗时（数小时 = 有人参与）、有没有独立的视觉基建、评论区作者回答「怎么改才能到你这个质量」。

## 追踪链路（从省到贵，命中即停）

1. **原帖 + 全部回复一次取完**：`curl https://api.fxtwitter.com/<handle>/status/<id>` 拿正文、计数和 `media.videos[]` 各码率直链。回复与作者自答用 nitter 类镜像的单帖页一次性读全文（`https://<mirror>/<handle>/status/<id>`），比逐条开 X 省一个数量级。**作者的技术口径几乎全在回复里**：用了哪个模型、花了多久、参考图怎么来的、以及给复现者的那两三条关键指令。
2. **找基建**：作者主页 / 置顶帖里通常早有一条「把它做成了 skill / 开源了」。README 里出现 `npx skills add <owner>/<skill>` 就是 Agent Skill（Claude Code / Codex / Cursor 通用格式），出现 `git clone` 就是普通仓库。
   ```bash
   curl -s https://api.github.com/repos/<owner>/<repo> | jq '{created_at,pushed_at,stargazers_count,size,description}'
   git clone --depth 1 https://github.com/<owner>/<repo> /tmp/<slug>     # 读用浅克隆，不要整仓
   ```
3. **只读三处，别通读**：
   - `SKILL.md` 的「硬规则 / 数字」段——作者把审片沉淀的数值写在这里，这是最值钱的部分（比例、像素、数量、时间曲线）。
   - `references/` 的目录与首段（`head -n 5 references/*.md`）：知道有哪些主题深度、要哪份再读哪份。
   - 代码库 API 清单，不要展开源码：`grep -n "^export " assets/lib/*.js`。一行一个能力，够写报告、够判断可复用性。
4. **跑得起来才算核实**：静态资源目录直接起服务看模板页（`python3 -m http.server -d <repo>/skills/<skill>/assets 8000`），有 `?test` / 结构采样页就先看那个，一眼能确认画风是否如宣传。
5. **抽帧实测，验证作者的说法**：
   ```bash
   ffmpeg -y -i src.mp4 -vf "fps=1/2,scale=480:-1" frames/f_%02d.jpg      # 全景联系表
   ffmpeg -y -i frames/f_%02d.jpg -filter_complex "tile=4x6" sheet.jpg
   ffmpeg -y -ss <t> -t 8 -i src.mp4 -vf "fps=1,scale=640:-1" tr_%02d.jpg # 转场段单独抽
   ```
   联系表只给 vision 读**结构与转场**（谁折起、谁弹起、镜头怎么走）；帧号、时长、文案回单帧读。`tile` 链里不要加 `drawtext`（本机 ffmpeg 常未编译该滤镜），按「第 N 格 × 间隔」推时间。
6. **报告骨架**：① 一句话结论（是 Skill 基建 + 模型执行 + 人工迭代，不是单条 prompt）；② 制作链路 4 步，每步写清「用到哪个组件 / 解决什么视觉问题 / 关键数值」；③ 抽帧实测（场景怎么串、转场机制是什么）；④ 复现入口（安装命令、本地预览命令、值得抄的组件清单）。作者的原话引用只用于「模型为什么选它」「花了多久」这类口径，不要用宣传语替代自己的实测。

## 可以抄进自家管线的通用手法

- **把审片沉淀的参数写成 skill 的硬规则**，而不是写进某个项目的一次性代码：下一支片子直接继承，不用重新调。
- **确定性截帧闭环**：页面暴露 `restart(); step(T)` 的固定时钟，Playwright 无头逐帧渲，再脚本化质检（穿模检测、报错、构件数量）+ FFmpeg 直接出多画幅 MP4。抽帧复核不靠人肉拖时间轴。
- **量化门禁代替「看着还行」**：过曝像素比、高饱和「网游绿」占比、暗部阴影色相是否发灰发黑、移轴清晰带占画幅比例、纸面/纹理细节 RMS。数值只是「不明显出错」的闸，形状与构图仍要人看。
- **盲审 A/B**：把目标概念图和渲染图拼成对比表交给 vision，多轮只修前三个问题、不无限加料。

## 工作例：立体书 / 纸艺微缩（pop-up papercraft，three.js）

MIT 开源 Skill `xikhar/papercraft`（`npx skills add xikhar/papercraft`，从作者自己的无限探索立体书游戏抽炼而来）。它是**纯代码**生成，不需要任何 3D 模型或贴图资产。看到「立体书卷轴 / 纸片微缩世界 / 折纸弹出」的画风，直接读这个仓而不是从零推参数。

| 模块 | 职责 | 关键手法 |
|---|---|---|
| `paperkit-2d.js` | 纸面与剪纸印纹 | `paperSheet`+`normalMap` 程序化出纤维/斑驳/纸齿；`printCard` 把每个物件画成「3–5 种油墨、多层剪纸叠加」并带短暖影与受光亮唇口——避免矢量平涂 |
| `paperkit-3d.js` | 让 WebGL 像实拍纸模 | 真厚度卡纸（厚度 ≈ 主角身高 1.5%–3%）+ 暗棕切边（1080p 下 1.5–2.5px）、仅受光侧一道细亮边；结构原语 `makeCard` / `layeredCard` / `crossCard`（90° 十字插接，防侧看变细线）/ `fanCard` / `boxFold` / `prismFold` / `platform`；`paperLights`+`enableSoftShadows`（PCSS，接地锐、离地虚、阴影带环境色）| 
| `paperkit-3d.js` 后处理 `PaperPost` | 微距移轴镜头 | 24°–32° 窄视角长焦、40°–55° 俯拍；景深按「屏幕高度 + 世界深度」混合，清晰带约画幅 36%–45%，1080p 模糊半径 12–18px；另含着色 SSAO、轮廓深度线、ACES 调色、颗粒 |
| `paper-motion.js` | 开合与微动 | 底边合页 `hinge` + 阻尼弹簧 `FlapSpring`：升起带 8%–15% 过冲、约 1s 稳定，部件错峰 0.05–0.1s；`windSway` 轻风；`FixedClock` 固定步长保证可复现 |
| `paper-sound.js` | 纸张拟音 | `synthFlap` / `synthStep` 全合成折纸声与脚步，`renderOffline` 离线渲染后与视频合流 |
| `paper-life.js` | 生态活感 | 天气微粒、飞虫鸟群、烟雾、云影、带行为的小生物 |

画风硬规则（作者审片沉淀）：纸哑光无高光；100–250 个构件、15–25 种、同款 ≤3 个、成组 4–8 个不同件；主角占 16:9 画幅高度 6%–10%；地面印刷品必须铺出画幅四边（不露天空/纸边/桌面）；大地平坦，起伏用「多层平行卡片按 10%–15% 明度阶梯叠」而不是抬高地形块；被踩/被钻进去的东西必须是 3D 构造（带桩的地台、带踏步的阶梯），不能用一张立卡充数。

卷轴片的运动机制：镜头固定俯角**水平横移**，扫过的旧场景沿合页向地面折平收起，进入视野的新场景按层次弹起，无硬切。做同款只需把「主角 WASD 自由行走」换成「固定轨横移 + 距离触发开合」。

**IP 题材的模型选择**（作者口径，也符合实测行为）：复刻任天堂/迪士尼这类知名 IP 时，Claude 系会因版权理由直接拒答，作者改用 Gemini 4 Neon；且新近发售的重制版美术不在预训练里，**必须先让 agent 下载一批原作参考图，必要时再生图出每页的概念目标图**，再让代码对着目标图搭。任何 IP 复刻都要在报告里提示：这类片不能商用分发，素材只作参考不随片发布。

## 常见误判

| 误判 | 纠正 |
|---|---|
| 把成片质量归给模型（「Gemini 4 Neon 太强了」）| 先看有没有现成 Skill/引擎：画风规则、结构原语、后处理都在仓里，模型只负责组装内容。报告要写清哪部分是可继承的基建。|
| 信「一句话就能出」 | 作者常自曝耗时数小时并需要持续 prompt 纠偏；把「框架 + 迭代」写成「一键直出」会让用户照着试然后失败。|
| 只看画面不看参数 | 这类画风的「像不像」全在数值上（厚度比、切边像素、清晰带占比、明度阶梯）；只写「很有纸感」等于没拆。|
| 拿开源 Skill 当万用模板 | 它是 plumbing（纸、卡、印纹、合页、光、镜头），每个题材的构件和构图必须自己设计；照抄示例世界的物件就是「照搬示范」。|
