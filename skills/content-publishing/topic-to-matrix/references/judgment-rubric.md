# 判断规则：做哪些形态、先做哪个

这是初始版本，阈值是智子的初始假设，不是平台数据得出的结论。每次复盘后在末尾「校准记录」追加，累积 5 条以上再动阈值；一次只改一个变量。

## 一、六个维度（各 0–5 分，写进 decision.json 的 scores）

| 维度 | 0 分 | 5 分 | 怎么判 |
|---|---|---|---|
| evidence 证据厚度 | 只有二手报道 | ≥ 12 条一手事实，含具体数字和日期 | 数 facts.json 条数和来源种类 |
| counterintuitive 反常识 | 教科书摘要 | 一句话就能推翻大多数人的默认认知 | 钩子本身也要有事实编号支撑 |
| visual 可视化 | 只能念稿 | 有数字变化、机制、对比，适合代码动画 | 能不能说出 3 个画面 |
| depth 叙事深度 | 一个点讲完 | 有冲突、有转折、能分 4 章以上 | 能不能列出章节问题 |
| global 中美共鸣 | 只有一边观众关心 | 中美观众都熟悉、都在讨论 | 看中英两轮搜索的结果 |
| risk 风险（越高越危险） | 无 | 医疗建议、政治、战争武器、金融建议 | 结合 video-common/compliance.md |

| ip_fit 个人 IP 契合度 | 与「不会写代码的职场人」无关 | 真实提问 + 卡在三步法某一步 + 并排实测 + 实测数字 | 见 `ip-principle.md` 第二节；公司号选题填 0 |

另写两个标签：`timeliness`（breaking 突发 / week 一周内 / evergreen 长青），`audience`（CN / US / both）。

## 二、形态规则

四种形态默认都要做（用户要求）。下面的规则决定的是**哪个打头、哪个推迟、哪个这次不值得做**。

**长视频**（YouTube 英文为主，B站中文版为次）
- GO：depth ≥ 4 且 evidence ≥ 4，并且 timeliness 是 evergreen 或 week。
- LATER：条件够，但本周审核预算不够；或是 breaking 新闻，等事实沉淀后做。
- SKIP：depth ≤ 2，撑不起 10 分钟（长片的时长和节奏见 youtube-channel-growth-playbook）。
- 英文切入点选美英加澳观众熟悉的事；中文版允许换切入点，但事实编号共用。
- 打头优先级最高：用户定了 YouTube 长片优先（单次播放收益最高）。

**短视频**（60–95 秒竖版；视频号为主，抖音同步，小红书 / B站 / 快手为次；英文版可投 YouTube Shorts）
- GO：counterintuitive ≥ 3 且 visual ≥ 3，且个人号 ip_fit ≥ 4（能并排实测）。ip_fit 不够时改写成长文，或先补实测。结构按 `ip-principle.md` 第四节。
- breaking 新闻优先短视频和贴图，抢时效。
- 长片 GO 时，短片取长片里最反常识的一个点，结尾导向长片。注意：Shorts 播放不计入 YPP 的 4,000 小时（见 playbook，用前重新核对）。

**图文贴图**（微信贴图为主，小红书图文为次，微博九宫格再次）
- 门槛最低：evidence ≥ 2 就能 GO；一帖 2–3 张图、同一主题（用户规则）。
- 事实清单类、数字对比类选题用卡片（ai-tietu）；素材是英文访谈/演讲时用字幕长图。

**长文章**（公众号为主；X 发英文 thread / 长帖；微博长文为再次）
- GO：evidence ≥ 3 且有可以写的「判断」段（用户偏好有观点的深度长文）。
- 长片 GO 时，长文先做：它就是长片的中文母稿，审一次稿子两边用。
- X 用英文，取 3–5 个最硬的事实 + 链接；中文版不直接翻译，按英文观众重写。

## 三、顺序的默认套路

- evergreen + 长片 GO：事实表 → 公众号长文（中文母稿）→ YouTube 英文长片 → 短视频 → 贴图 → X → B站中文长片 → 微博/快手。
- breaking：贴图 + X（当天）→ 短视频（1–2 天）→ 长文（2–3 天）→ 长片标 LATER。
- 长片 SKIP：长文或短视频打头，另外两个派生。

## 四、预估审核小时（初始值）

| 形态 | 初始值 | 依据 |
|---|---|---|
| 长视频 | 3 | youtube-channel-growth-playbook：每条约 2.5–3 小时审核 |
| 短视频 | 1 | 估计，待校准 |
| 贴图 | 0.5 | 估计，待校准 |
| 长文 | 1 | 估计，待校准 |
| 每多一个平台的文案 | 0.1 | 估计，待校准 |
