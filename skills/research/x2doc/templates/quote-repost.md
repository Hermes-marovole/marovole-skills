# 宝玉风格 Quote Repost 模板

**使用场景：** 用户发送 X 链接并说 "x2doc repost" 时，生成中文引用转发文本，供用户手动粘贴到 X 的 Quote 框。

**Agent 不碰 X API！** 不要尝试 xurl 自动转发、点赞、回复。

---

## 格式规范

```
🔥 { 一句话标题，点出价值 }

{ 1-2 句钩子，让中文读者想点开原帖 }

1️⃣ { 要点一，一句话 }
2️⃣ { 要点二，一句话 }
3️⃣ { 要点三，一句话 }
4️⃣ { 要点四，一句话 }

💡 { 1-2 句价值解读，告诉中文读者这对他有什么用 }

via @{original_author_handle}
```

## 规则

- **🔥 打头 + 强标题** — 社交媒体扫描友好，让人想点开原帖
- **编号要点** — 用 1️⃣ 2️⃣ 3️⃣ 4️⃣，每点一句话，不展开成段落
- **结尾 credits** — `via @handle` 致谢原作者
- **不附链接** — 除非用户明确要求，否则不要加 `📄 完整文档` 链接
- **纯文本输出** — 不要加标题、分割线、解释性文字

## 示例

```
🔥 llama.cpp MTP 实测：12GB 消费卡跑 35B 模型，提速 50%+

AI 工程师 @ItsmeAjayKV 在 RTX 3060（12GB）上实测了刚放出的 Qwen3.6-35B-A3B-MTP 量化版，用 llama.cpp 跑出了非常扎实的参数调优结论：

1️⃣ MTP 提速显著：无 MTP 约 21 t/s，开启后 30–35 t/s，提升 50%–67%

2️⃣ 不是越深越好：--spec-draft-n-max 的甜蜜点在 2–4，盲目加深反而降速

3️⃣ VRAM 是硬约束：ngl 和 ncmoe 此消彼长，多堆 GPU 层提 tg 但 expert 必须让路

4️⃣ 长上下文是下一关：128k+ context 下 MTP 的 KV cache 驻留策略比预期更复杂

💡 对于手里只有 8–16GB VRAM 的本地推理玩家，这套参数组合（ngl 6 + ncmoe 28 + n-max 3）可以直接抄作业。M2 Max / DGX Spark 上的同学也可以对照验证。

via @ItsmeAjayKV
```
