# 中国公司工商 / 股权 / 司法穿透核查清单

用于公司尽调（投资、商务签约、竞品背调、挖人判断）。目标不是"查到注册资本"，而是还原**谁真正控制它、钱从哪进、风险埋在哪**。

## 0. 轴心：统一社会信用代码

品牌名 ≠ 法律主体。先定位境内运营主公司的信用代码，再用代码反查一切。

- 公司名常改（"XX科技"→"XX智能"），代码不变。曾用名要单独记，备案与商标多挂在旧名下。
- 代码命中后可连带查：法院开庭公告、招投标记录、商标/专利/软著件数、行政许可。
- 专利件数是个好用的反向指标：估值几十亿但境内专利只有个位数，说明它是工程/应用层公司，不是研究型实验室——这一点应写进报告，因为它决定护城河判断。

## 1. 主体图谱（报告里做成一张表）

列：公司法律全称 / 统一信用代码或注册地 / 成立日期+法定代表人 / 注册资本+实缴+参保 / 在集团中的真实角色。

要穷举的主体类型：

1. **境内母公司**（通常即 VIE 协议控制对象）：持 ICP 备案、算法备案、商标；参保人数是真实团队规模的下限。
2. **业务专设全资子公司**：在新产品上线前夕注册，法定代表人常与母公司同一人，经营范围覆盖对应增值电信业务。**注册日期与产品发布日的时间差本身就是证据**。
3. **异地研发/出海子公司**：一线城市之外的"第二总部"，招聘 JD 集中地，反映真实战略重心。
4. **员工持股平台**（多为"企业管理发展中心（有限合伙）"）：认缴额=期权池比例。
5. **已注销的分支/旧主体**：早期联创或旧架构痕迹，配合组织变动叙事。
6. **境外主体**：开曼（融资/上市壳）、特拉华 C-Corp 或香港公司（海外收款、商标持有）。境外主体从国内工商查不到，见第 4 节。

## 2. 股权变更：VIE / 红筹判定

**症状**：媒体写了 N 轮融资、股东名单里有若干知名 VC，但当前工商股东只有创始人 + 员工持股平台。

**不要**据此判断融资造假。标准红筹路径：美元基金投开曼母公司 → 境内 VC 从境内主体减资退出（行话"翻出境外"，换开曼优先股）→ 境内留纯内资以符合 ICP / 大模型备案的外资限制 → 通过协议控制把境内利润并表。

**三条判据**（齐全即可写进报告）：

1. 历史工商快照/变更记录里，早期轮次的 VC 曾显名持股（"XX股权投资合伙企业"即基金 SPV，需翻译成背后的 GP 品牌：源码/高榕/金沙江等）。
2. **算术校验**：各 VC 认缴额之和 == 当前"实缴资本"，且各自占比与轮次稀释比例吻合。这条最能说明"钱真的到过境内又退出"。
3. 招股书、券商辅导备案或权威媒体口径里出现"拆红筹 / 架构重组 / 红筹回归"。拟上市阶段这条几乎必然出现。

报告写法：做一张"变更前 vs 变更后"双列股东表（股东 / 背后真实资本方 / 变更前比例与认缴 / 变更后比例 / 变动性质判定），比一段文字解释有力得多。

## 3. 备案资产：免费但信息量最高

- **ICP 备案历史库**（如 `icplishi.com`）：一个备案号下的全量子域名 + 各子号最后更新时间。读法——① 新产品线命名规律（主站、`.cn`、`.art`、英文谐音全套占位）；② 顶级域名抢注动作（近期才备案短域名 ⇒ 正在重金收域名）；③ `abtest`/`test` 类域名 ⇒ 数据增长团队在做付费墙实验；④ 旧品牌域名 ⇒ 出海曾用名与失败项目。
- **网信办大模型/算法备案**：名称、备案单位、属地、类型、备案编号、受理与公示日期。**不带 `S` 的编号是真·大模型备案，带 `S` 只是应用/算法登记**。受理到公示的天数可用来讲"合规推进速度"。
- **商标**：境内外分开查。境外商标的申请时间与数量（一次连续申请十几件）常是诉讼里的关键事实。

## 4. 境外主体与诉讼（出海公司必查）

- **PACER**：`pacermonitor.com` 提供公开 filing 的 PDF；`courtlistener.com` 可免费查 docket。关键词用英文品牌名 + `v.`。
- 起诉书的价值不止"被告了"：第 1–2 页的公司描述段（"X is a Delaware corporation ... and is a subsidiary of Y"）直接给出境外主体名、注册州、办公地址、与境内母公司的关系——这是国内工商永远查不到的一环。
- **USPTO/TTAB**：查在先商标、注册号、priority date、国际分类，判断"恶意抢注"指控是否站得住。
- 判决影响要落到商业后果：海外主品牌被禁令 ⇒ 改名成本 + 招股书或有负债，这属于重大风险项，不能只作为花絮列出。
- 国内诉讼查开庭公告（法院 + 案号 + 案由 + 时间），案由本身有信息量（"网络域名权属纠纷" ⇒ 域名争夺，配合 ICP 新备案一起读）。

## 5. 付费接口（用户问"有没有 API"时给这一节）

| 通道 | 入口 | 门槛 | 适合 |
|---|---|---|---|
| 天眼查开放平台 | `open.tianyancha.com` | 企业认证 + 按次充值（约 ¥0.1–0.5/次） | 批量拉股东穿透、历史变更、涉诉、实控人图谱（JSON） |
| 企查查开放平台 | `openapi.qcc.com` | 同上 | 同上，字段口径略有差异，可交叉校验 |
| 启信宝 | 官网开放平台 | 同上 | 同上 |

回答要点：接口能给**结构化、可批量、可复跑**的字段；免 Key 通道给**非结构化但更深**的信息（历史快照、备案子域名、境外卷宗）。做一份报告用后者，做持续监控/入库用前者。

## 6. 常见误判

- 把"参保人数"当成员工总数（外包、劳务派遣、境外主体员工都不计入）。
- 把"注册资本"当实缴（认缴期限可到 2050 年，几乎没有信息量）。
- 把基金 SPV 名（"XX源夏""XX五期一号"）当成独立投资方，实际要翻译回 GP 品牌才有叙事价值。
- 只查当前快照，不看历史变更——股权故事全在"变更记录"里。
