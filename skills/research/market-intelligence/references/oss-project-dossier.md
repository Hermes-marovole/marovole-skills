# 单仓开源项目尽调（工具 / 底座 / 组件）

适用：用户丢一个 GitHub 仓库或一条介绍帖，问「调研一下这个工具」「能不能用在我们场景」「有没有坑」。与招股书 / 财报调研不同，证据几乎全在仓库里，一手取证成本低，但结论必须过「本机跑一遍」这一关——只读 README 写出来的判断就是替作者写通稿。

## 1. 四层取证（顺序固定，逐层变硬）

1. **元数据层（GitHub API）**：`https://api.github.com/repos/<owner>/<repo>`、`/releases/latest`、`/contributors` —— stars、forks、open issues、`created_at`、`pushed_at`、license、最新 tag、主要贡献者。这层只证明「有人在维护、节奏如何」，不证明可用。
2. **架构层（raw 文档，不读 README 摘要）**：`raw.githubusercontent.com/<owner>/<repo>/main/docs/<file>.md`，外加 `pyproject.toml` / `package.json`（看依赖数量与 extras：依赖越少，越可能是能直接嵌进自己系统的组件）。优先抓 pipeline / standardization / 权限与数据访问 / 数据模型这四类文档，用来讲清「它替你解决了哪一步，把什么留给你」。
3. **实测层（本机黑盒，最高等级证据）**：Python 用 `uvx --python 3.12 <pkg> <subcmd> …`，Node 用 `npx -y <pkg>`。**装完判断一次是否离线可跑**（无 key / 关网重跑）：宣称「零 API Key、本地运行」的工具，这条必须自己验，不能引 README。同时记录安装体积与包数，组件化评估全靠它。
4. **商业 / 许可证层**：`LICENSE` 实际条款；开源版与托管版的功能切分（定价页 + docs 的 feature 对照，找出「闭源独有」的那几项，通常正是企业客户真正付费的点）；数据归属（是否上传云端、分享链接的权限模型与 TTL、删除语义）。

## 2. 实测怎么做才叫证据：构造 `x/N` 召回表

禁止写「实测效果不错」。固定一个**可复述的样本集**（如 27 个中文体检与营养高频指标、20 种常见日志格式、15 条真实 SQL），跑一条命令拿到逐条判定，然后三栏记账：

- **命中**：列出它返回的标准码 / 结构化字段的至少 5 个具体值，证明不是抽样自述；
- **正确拒答**：类别词、组合项（「血脂」这种一单多测的名字）返回「无法编码」是加分项，单列一栏，**不要并进失败率**；
- **未命中 / 失败**：附失败形态原文（如 `not in the lexical index`）。

三栏之和必须等于 N。中文场景重点记录「差一个字 / 多一个前缀」的近邻变体（`25-羟维生素D` vs `25-羟基维生素D`、`血清铁蛋白` vs `铁蛋白`、全大写缩写 vs 中文名）——这类漏召回才是国内落地的真实改造成本，也是报告里唯一有说服力的「会卡在哪」。

## 3. 结论的形状（用户要的是「该不该用」）

- 一句话定性（它是什么 + 不是什么）+ 三到四个计数 KPI：维护热度（stars / 版本 / 发版节奏）、工程体积或依赖数、实测命中率、开源 / 付费切分的价格锚点。
- 两条判断框：① 它的工程克制在同类里什么水平——举它明确拒答、拒绝猜测的具体行为；② 拿到**我们自己的场景**会卡在哪——用未命中率量化，并给出补齐代价（补一层同义词表 / 写一个适配器 / 换数据源）。
- 架构与数据流按「工序」讲（输入 → 归一 → 编码 → 落库 → 对外接口），不按文件目录列表讲。
- 边界写硬：算法定义不一致（同一指标不同厂商算法不可直接比较）、基因组 / 用药这类不能随便映射的领域、以及「开源版不提供什么」。
- 收尾给「适用 / 不适用清单 + 三步接入路径」，不要一段总结陈词。

## 4. 坑

- **星数与发版频率不是可用性证据**：能不能上生产看版本阶段声明、安全记录、供应链与权限模型四件事（见 SKILL.md 同名条目）。
- **README 的「支持 N 种格式 / M 个指标」要落到 docs 与实际枚举**，并抽样验证其中 3–5 个；照抄宣称是最容易被用户在实测里打回的一句话。
- **实测百分比只在「本轮样本集」上成立**，报告里必须写出样本集是什么、多少条、测试环境（Python 版本、包版本、是否离线），否则下一个会话会把它当全量精度。
- **命令输出必须落盘并进台账**：原始输出存 scratch，正文每个数字都能回指一次真实命令；引语用真实输出，不手改措辞。
