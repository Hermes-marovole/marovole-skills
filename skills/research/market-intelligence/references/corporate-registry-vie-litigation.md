# 企业工商穿透、历史股权逆向、VIE架构与跨国诉讼调查手册 (Corporate Registry, VIE & Litigation Playbook)

用于未上市独角兽、AI 初创公司、跨境出海企业或拟上市公司的商业尽调。目标是穿透公关通稿，还原**真实经营主体矩阵、早期 VC 稀释比例、VIE 红筹拆搭痕迹、工信部/网信办备案资产与中美涉诉底牌**。

## 1. 数据源分层：付费 API 接口 vs 零成本公开权威库

### 1.1 商业付费 API（适合企业内部大批量自动化接入）
| 平台 | 官方接口入口 | 核心端点（Endpoints） | 准入与计费 |
| :--- | :--- | :--- | :--- |
| **天眼查开放平台** | `open.tianyancha.com` | 企业基本信息、股东及出资信息、历史工商变更、股权穿透图、企业风险/涉诉 | 需企业营业执照实名认证；按次计费（约 ¥0.10–¥0.50/次）或年度接口包 |
| **企查查开放平台** | `openapi.qcc.com` | 工商登记穿透、实际控制人路径、历史股东、知识产权（商标/专利/软著/ICP） | 需企业认证；提供 REST JSON 接口 |
| **启信宝开放平台** | `open.qixin.com` | 关联族谱、董监高对外投资与任职、司法裁判文书与开庭公告 | 需企业认证 |

### 1.2 零成本公开权威穿透源（Agent 实时检索首选组合）
无需企业 API Key 即可跑通完整证据链的 6 条公开通道：
1. **境内工商快照与历史变更穿透**：检索天眼查（`tianyancha.com`）、企查查（`qcc.com`）、爱企查及第三方创投工商存档站（如 `k1wave.com/company/...`、`vc.pedaily.cn`、`pitchhub.36kr.com`），提取：统一社会信用代码、法定代表人、注册资本、**实缴资本**、参保人数、**历史退出股东名单与退出前精确认缴额**。
2. **工信部 ICP 备案与历史域名库**：检索 `icplishi.com/<备案号>` 或 `beianx.cn`，拉取母备案号（如 `京ICP备xxxx号-1` 至 `-N`）下挂的全部子备案域名与核准日期。
   - **核算铁律**：注意区分「最大子备案编号（如 `-36`）」与「现存在册有效域名数（如跳过 4 个已注销子号后实存 `32` 个）」，严禁只看末尾编号直接写总数。
3. **国家网信办生成式 AI 大模型与算法备案库**：检索网信办备案公示清单或聚合库（如 `opckits.com/models/...`），查明备案模型名称、备案号、备案主体与上线日期（往往能挖出公司早期的内部项目代号，如演语科技的「片羽图像生成大模型」）。
4. **境内法院开庭公告与裁判文书**：检索「公司全称 + 民初 / 知民初 / 开庭公告 / 法院」，提取案号（如 `（2026）沪0115民初xxxx号`）、案由、原被告及开庭排期。
   - **VIE 股东口径铁律**：引用被告/原告工商股东（如上海幻电信息科技有限公司登记股东陈睿 52.30%、徐逸 44.31%）时，必须明确标注为**「境内 VIE 运营主体工商登记名义股东」**，严禁与美股/港股上市公司（如 Bilibili Inc.）的经济持股比例或投票权混为一谈。
5. **海外运营主体逆向定位**：直接抓取其海外产品官网的 `/terms-of-service`、`/privacy-policy` 或 Stripe 结账页底部法律主体名称与注册办公地址（如从 `lovart.ai` 隐私政策抓出美国特拉华州主体 `Resonate International INC.` 及加州 Sunnyvale 办公地址）。
6. **美国联邦法院 PACER 诉讼卷宗与 USPTO 商标库**：用海外主体英文全称检索 `pacermonitor.com`、`dockets.justia.com`、`courtlistener.com` 及 `uspto.report`：
   - 查明联邦地区法院案号（如 `1:26-cv-00990`）、原告、起诉日期與涉案注册商标号；
   - 统计 USPTO 商标申请总数时，必须写清商标词构成（如「共 13 项美国商标，含 12 项 `LOVART` 与 1 项 `SHAKKER`」），防止跨页引用时出现 13 项 vs 12 项的数字打架。

## 2. 从「实缴资本」与「历史退出股东」反推天使轮稀释比例与 VIE 架构

很多美元/双币基金投资的中国 AI 独角兽，当前工商股东名册里只有「创始人 + 员工持股有限合伙（ESOP）」，看不到任何 VC。外行常误以为「这家公司没拿过机构钱」或「机构撤资了」。报告中必须用两步数学与法务逻辑讲透：

1. **用历史股东认缴额精确复原首轮稀释比例**：
   - 找出 VC 退出前的历史注册资本总额 $C_{\text{total}} = C_{\text{founder}} + C_{\text{VC}}$；
   - 每家 VC 的真实持股比例 $= \text{该 VC 认缴注册资本} \div C_{\text{total}}$；
   - **机构数 vs 基金主体数铁律**：同一家 VC 常拆成多只基金主体签字（如高榕拆为南京高榕 + 三亚高榕两只合伙企业），正文中必须写清**「N 家早期风投机构（旗下 M 只基金主体）」**，严禁把 3 家机构旗下的 4 只基金加创始人凑成「5 家早期 VC」。
2. **解释为什么现行工商快照常留着一笔「零头实缴资本」**：
   - 境内早期增资时，创始团队认缴的基准注册资本（如 100 万元）通常设定远期认缴期限（如 2029/2050 年）而暂未实缴，只有外部 VC 真金白银完成了新增注册资本（如 28.5715 万元）的实缴验资；
   - 随后公司为引入美元基金或筹备港/美股上市搭建**红筹 VIE 架构**（开曼控股 → 香港壳公司 → 境内 WFOE 协议控制境内运营主体），境内 VC 基金办理减资退出并平移至开曼公司拿优先股，境内注册资本恢复为 100 万元，但工商年报数据库里的历史累计实缴字段往往仍保留着当年 VC 实缴的 `28.5715 万元` 印记。
   - **表述禁忌**：严禁写成「用 128.5715 − 100 = 28.5715 万证明与实缴资本一分不差」的同义反复，也不要在同一句话里既说「已减资退回」又说「至今实缴仍为 28.5715 万」而不解释其为工商年报历史留存字段。
