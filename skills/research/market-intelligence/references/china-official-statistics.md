# 中国官方统计数据取数手册（人口与宏观基数）

用户问「中国有多少 X 人群」（育龄女性、慢病患者、老年人口、新生儿）时用本手册。核心纪律：**只认国家统计局实测口径 + 时点标注**，自媒体二手数只能当线索。

## 1. 数据源层级（从硬到软）

| 层级 | 源 | 用途 | 坑 |
| :--- | :--- | :--- | :--- |
| 实测锚点 | 第七次全国人口普查（2020.11.1 零时） | 分年龄分性别最细的全面实测，十年一次 | 数据表以图片发布，见 §2 |
| 年度实测 | 国家统计局年度统计公报（stats.gov.cn） | 年末总人口、出生数、分性别总数 | 不分年龄组 |
| 抽样实测 | 1% 人口抽样调查（逢 5 年份，11.1 零时） | 总人口、15—59 岁大组 | 公报不公布 15—49 岁女性；分性别年龄要等次年年鉴 |
| 国际对比 | 联合国 WPP（可经 worldpopulationreview 转引） | 跨国对比、趋势校验 | 对中国绝对值总体偏高（多数年龄组高于七普，少数相反），只能用于趋势与量级 |
| 第三方镜像 | 数读城事 citydast 等 | 把七普原表转录成文本，便于加总 | JS 渲染页，curl 拿不到，需浏览器实取 |
| 学者解读 | 何亚福、梁建章/育娲、泽平宏观 | 趋势机制、预测、口径讨论 | 引语必须回原文核对，见 §5 |

## 2. 年鉴数据表是图片，别用 curl 硬啃

《中国人口普查年鉴2020》表 3-1 这类核心表以 JPG 发布（如 `A0301.jpg`），`curl`/`web_extract`/firecrawl 只能拿到 HTML 壳和图片链接，拿不到数字。正确路径是**三源互证**：

1. `vision_analyze` 直接读原表图片，按「合计 = 男 + 女」逐组互验，7 个 5 岁组合计应闭合；
2. 第三方镜像站逐组转录后自己用 Python 加总（不要信镜像站自己写的合计）；
3. 学者文章里引用的同表数字（何亚福、梁建章团队）。

三条路径落到同一个数（如 15—49 岁女性 32229 万，加总 32229.2 万）才算锚定。

**分母陷阱**：七普表 3-1 合计 140978 万**不含现役军人**；公报全国人口 141178 万**含军人**。算占比时用错分母，百分比差 0.03pp 级别，写报告要同时给出两个口径并注明用的是哪个。

## 3. 人口口径表（不可互换）

| 口径 | 年龄 | 出处 |
| :--- | :--- | :--- |
| 育龄女性 | 15—49 岁 | 联合国 + 国家统计局通用 |
| 生育旺盛期 | 21—35 岁 | 国家统计局 |
| 生育主力 | 20—39 岁 | 人口学者常用 |
| 主力育龄妇女 | 20—35 岁 | 泽平宏观 / 育娲 |

「生育旺盛期 21—35」与「主力育龄妇女 20—35」只差 1 岁，但出自不同机构，**引用时不可互换、不可省略出处**。同理 15—49 岁总量不等于目标人群：15—19 岁段（七普 3363 万女性）基本不在孕产/女性健康消费场景内，做市场测算必须按年龄段切分。

## 4. 时点规则

- 普查 = 时点数（11 月 1 日零时）；年度公报 = 年末数；1% 抽样调查 = 11 月 1 日零时。三个时点**不可混用**，报告里每个数字都要带时点。
- 「目前」的官方数字永远滞后：2026 年的分年龄数据要等《中国人口和就业统计年鉴2027》（收录 2026 年数据）。没有官方数就写「按七普推算」并标 `[未核实推断]`，不要拿外推数冒充官方数。
- 年鉴年份命名：年鉴 N 收录 N-1 年数据。写「等年鉴出版」时年份要加 1，这是最容易被审计抓到的低级错。

## 5. 趋势机制的正确写法

育龄女性规模 = 对应年份出生人口队列的滚动：2023 年的 15—49 岁女性出生于 1974—2008 年；1968—1973 年平均每年出生 2600 多万，远高于 1974 年及之后几年，所以退出育龄段的队列大于进入的队列。

**机制段必须挂到真正写过这句话的源**。「初轮搜索里见过」不等于该源含此句——审计抓到引语挂错源时，回源确认后把它登记为新的台账源并挂引语，不要直接删句（内容真实，删了丢论证）。

## 6. 永久锚点（可直接引用）

- 七普 15—49 岁女性：**32229 万**（2020.11.1，加总 32229.2 万）
- 七普 20—39 岁女性：约 2.1 亿；15—19 岁 3363.1 万；45—49 岁 5603 万
- 历史峰值：2011 年 3.8 亿；2011—2022 年年均减 618.9 万
- 育娲中方案：2030 年约 3 亿、2050 年约 2.1 亿（预测，非实测）

非永久数字（年度推算、抽样调查结果）每次调研都要重新抓，不要从本文件抄。
