## 一、彩云小梦（彩云科技 / 北京彩彻区明科技有限公司）

### 定位与目标用户
- 国内最早的 AI 故事续写产品（2021 前后出圈），主打"给一个开头，AI 帮你续写"。官方 App Store 描述强调"AI 聊天、AI 写作 + 角色扮演/世界广场社区"，逐步从写作工具演化成"创作+互动故事社区"双形态。
- 目标用户偏轻量创作/娱乐型用户（同人续写、脑洞、角色扮演），而非日更万字的全职网文作者。

### 核心功能
- **设定管理：有（社区化路线）**。"世界设定"功能可创建普通词条、人物词条、人物之间的关系，并附加背景故事帮助模型理解世界观；设定可公开到"世界广场"分享。
- **章节蓝图：无传统大纲/章纲体系**。续写以分支树形式呈现（"平行世界/后悔药"回溯到任意续写节点），不做总纲-卷纲-章纲的规划式管理。
- **前文上下文控制：弱**。按续写式短上下文运作；萌娘百科记载其单部作品支持上限约 10 万字（超出提示创作迟钝），该口径待核实。
- 其他：多风格模型（标准/言情/玄幻/纯爱/脑洞/细节狂魔）、续写长度自定义、文字/语音聊天角色扮演、一键生成分享图。

### 模型接入与收费
- **接入：闭环**。依托自研模型，应用宝介绍提及接入 DeepSeek R1、豆包等大模型（面向写作/对话），用户不能接入自有 API。
- **收费：会员订阅 + 次数限制**。免费用户每日续写次数有限，付费解锁；iOS 端自动续费为 25 元/月、48 元/季、188 元/年（App Store 页面口径）。专业版续写模型（V2/V3.x）面向会员。

### 平台形态与数据
- 网页版 + iOS/Android App（iPad 适配）。创作、世界设定、广场社区均云端托管，作品默认存在平台云侧，本地导出能力未见公开说明（待核实）。

### 竞争观察（相对 Pagekin）
- 是 Pagekin"设定管理"维度的国内鼻祖级参照（词条/人物/关系结构），但其定位是"社区娱乐型续写"，不绑 API、无大纲蓝图、无本地存储——与 Pagekin 的"本地优先、模型中立、长篇工具"三条核心卖点几乎完全错位。

## 二、笔灵 AI 写作（上海简办网络科技有限公司）

### 定位与目标用户
- "全能型 AI 写作工具"集合：AI 写作模板（200+场景）、AIPPT、论文/降AI率服务，以及独立的"AI 小说"模块（300+ 网文生成器、百万资料库）。小说模块目标用户为网文新人（黄金开头、过稿大纲、去AI味、拆书、投稿攻略）。
- 平台明确针对"体制内人、作家编辑、大学生、职场人士"多人群，小说只是其一。

### 核心功能
- **设定管理：弱（提示词级）**。用户在生成器中输入小说名、风格、角色名、世界观、主题等一次性参数；无独立人物库/世界观档案。
- **章节蓝图：有生成、无管理**。提供"小说大纲助手、梗概生成、剧情创作"等一键生成器（宣传"编辑认证大纲"），生成后的大纲不在作品级项目中长期管理。
- **前文上下文控制：无**。一次性生成/续写，无前文记忆库和设定联动；有知乎作者实测称"买终身会员实际附送 50 万字额度，生成一次几千字，用完再充值"（该体验为第三方帖，官方条款待核实）。
- 特色：AI 写全篇小说（一键长文）、拆书、模拟编辑审稿、小说去AI味、调研称其配套的小说导航站/资料库是其引流配套。

### 模型接入与收费
- **接入：闭环，不开放自定义 API。**
- **收费：会员 + 字数包，且小说模块与主站会员分开计价**。官网挂"终身 VIP 199 元"（主站），活动页显示"主站终身会员 199 + 小说终身会员"合计促销；开通小说会员赠送 50 万 AI 字数，用完另购字数包。第三方帖确认"终身会员无法用在小说写作上"（反馈口径，待核实官网细则）。

### 平台形态与数据
- 网页为主，另有 Windows 应用商店客户端/App；作品存于平台云端（站内保存），可导出文档。无本地化存储选项。

### 竞争观察
- 走的是国内典型的"低价终身会员+字数消耗"网赚模型，与 Pagekin 的开源/不绑模型形成强对比；在长篇上下文管理上属于"无此能力"一档，可作为"国内主流闭源工具 vs 本地优先开源工具"对照柱。

## 三、蛙蛙写作（杭州引力智航科技 / 原波形智能 AIWaves）

### 定位与目标用户
- 网文与短剧作者的生产线：从大纲、人物、正文续写全流程，向下打通"小说→剧本→漫剧视频"，向上有"在线投稿变现"通道。2024-01 上线，曾宣称付费次留 45%、人均使用 4.7h、付费率超 4%（36 氪报道，发布于 2024，数据时效请以最新为准）。
- 目标用户：全职网文作者与短剧编剧；官方定位"卡文/灵枯/变现难三大痛点"。

### 核心功能
- **设定管理：有（结构化）**。官方 FAQ 与多家工具收录均确认支持"总纲、卷纲、章纲、人物、世界观的结构化管理"，AI 生成时从约 30+ 作品数据字段自动拉取上下文（App Store 文案），保证正文贴合主线。
- **章节蓝图：有**。总纲/卷纲/章纲三级大纲，另配头脑风暴、模板/题材标签、伏笔管理（自研 Weaver 支持动态长短期记忆，伏笔存长期记忆）。
- **前文上下文控制：有（较强）**。 "动态长短期记忆机制"（量子位访谈）+ 作品数据自动拉取 + 自由对话式创作；另有拆书工具、知识库/素材库。

### 模型接入与收费
- **接入：曾为自研垂域 Weaver/Weaver 2.0 单一模型**；App Store 侧描述"多款 AI 模型辅助"（2024-10 波形智能并入 OPPO 后，模型栈是否开放第三方接入待核实）。
- **收费：蛙币计量 + 会员**。新用户送体验蛙币；AI知见（2026-09 核验）称"会员周卡 9 元起"；iOS 内购档位含无限卡（1.99–299.99 美元多档）与金/铂/黑金会员包年（59.99–199.99 美元），官网人民币定价以会员中心为准。
- 官方公开承诺"不会将用户上传或发布的作品用于 AI 训练"（官网 FAQ，2026-08 版本）。

### 平台形态与数据
- 网页（wawawriter.com）+ iOS/Android App + 微信小程序 + 客户端（部分渠道），多端云同步；作品与设定存云端。

### 竞争观察
- 与 Pagekin 重叠度最高的 productId：同为"设定+多级大纲+正文"三件套；差异点是蛙蛙为云端 SaaS + 自研模型 + 会员/蛙币计费 + 大量热门模板工作流，而 Pagekin 是开源本地 + 用户自有 API + 无模板诱导。

## 四、墨狐AI（Inkfox / inkfox-ai.com，北京云泥科技）

### 定位与目标用户
- 网文短篇/开篇向轻量 AI 助手。第三方评测归为"风格化仿写与扩写"型工具：给一段干叙述，可扩写成特定文风（古言/废土等）段落，站侧亦有编辑视角的开篇冲突优化（"强化钩子、规避慢热"）。

### 核心功能
- **设定管理：有限**。生成大纲时自动产出"导语+世界观+角色卡+作品目录"，可自定义修改，但为一次性产物；有无独立人物/世界观档案库待核实。
- **章节蓝图：轻量**。大纲含"作品目录"（章节目录），有"剧情树"功能可视化为后续可能走向图；无总纲/卷纲/章纲层级体系。
- **前文上下文控制：一次性**。"续写故事"需用户给定上文，指定生成字数与画风/剧情走向；无跨章节自动联动。
- 其他：素材生成器（一键存为卡片）、小说转剧本。

### 模型接入与收费
- **接入：平台自带（官方称中文创作超越 GPT 的宣传口径）**，未公开具体模型与 API 自定义选项。
- **收费：AI工具集标注为"免费增值"模式**；具体会员/字数价格待核实（官网未在本次搜索结果中披露）。

### 平台形态与数据
- 网页工具（inkfox-ai.com），移动端未见公开 App；作品存云端。

### 竞争观察
- 面向短篇/开篇的"轻量模板型"竞品，长篇上下文与设定档案不是其核心主张；月访问量仅约千级（yiban 流量面板，2025-06 发布后一段时效），体量较小。

## 五、星月写作（xingyuexiezuo.com）

### 定位与目标用户
- 网文"全流程 + 变现生态"产品：扫榜（番茄各细分榜今日风向/题材热词）、拆书仿写、大纲/细纲/黄金开篇/人设/世界观生成、正文续写、润色去AI痕迹，再叠加短剧改编辅助与"课程+社群"变现生态。主打"想赚钱/兼职副业"的网文与短篇作者。
- 2024-06 上线，创始团队 8 人，上线一年月活 2 万+，宣称月入上百万元、付费率超 17%（36 氪/极客公园口径）。

### 核心功能
- **设定管理：提示词级+知识库**。以"词条卡/十万级提示词生态"形成轻量设定库；有"关联知识库功能"辅助长篇一致性（哇噜剧厂测评把它列为★★★★☆，与马良并列较高档）。
- **章节蓝图：全流程拆细**。创意→大纲→细纲→黄金开篇→正文→续写→润色每步独立工具，配套"保姆级教程"视频。

## 十二、开源/工作流生态（网文圈"折腾型"玩家的_decode 圈）

> 这里是"开源工作流/工具"圈，与 Pagekin 本身定义有最直接参考价值。搜索中确认的产品/项目如下（**未在搜索中确认到名为 "WorldSmith" 的国内产品**——该名字更接近海外 World Anvil 生态，标注待核实；也未确认"CaiyunHua" 独立产品，可能为口碑术语/玄学词，待核实）。

### 12.1 墨狐外其他开源建模
- **AI-Novel-Writing-Assistant（ExplosiveCoderflome）**："AI 自动导演开书→卷纲+角色→正文→章节串行生成"的 AI Native 工作流，开源免费。当前作为开源对标可直接引用。

- **InkOS**（知乎 IntelliJ diao 相关评测/文档描述）：CLI 多 Agent 管线（雷达-建筑师-写手-审计-修订），真相文件（particle_ledger/pending_hooks/character_matrix 等） + 26 维审计。
- **墨扉（dsh-mofei）**：DeepSeek Harness（DSH）工作台，Cordis 插件实现"人写草稿→Agent 润色→Reviewer 把关"。
- **oh-story-claudecode（zenstory-ai）**：Claude Code / Codex / OpenCode 的 skill 合集（扫榜、拆文、写作、去AI味、封面）。
- **chronicler（a9549521/chronicler）**：长篇小说 AI 工作台。
- **quillgon、StoryMemory-Studio**：强调"结构化故事记忆+一致性检测"的开源工作台（StoryMemory-Studio 自称本地优先）。

### 12.2 共同技术路线（对 Pagekin 有直接参考）
- **"文件/数据库承载真相（状态）→生成前拼上下文→生成后审计/回写剔除幻觉"** 的 RAG+Agent 工作流已成国内开源圈共识。这是 Pagekin 本地 SQLite + 前 文上下文控制 追求同一目标的不同实现路径。

## 十三、总体要点（结论草稿，供主报告撰写使用）

1. **市场分层明显**：国内竞品大致分四档——
   - **社区娱乐型**（彩云小梦）：弱长篇能力，偏互动/续写体验，云端+自研模型；
   - **SaaS 网赚型**（笔灵、星月、墨狐、灵犀）：会员/字数包为核心、靠爆款模板和"变现"叙事增长，多靠平台自有模型，无自定义 API 或仅灵犀/马良支持；
   - **专业深度型**（蛙蛙、马良、FeelFish）：结构化设定+多级大纲+上下文管理三件套，与 Pagekin 直接对标；
   - **开源/工作流型**（AI-Novel-Writing-Assistant、天命、InkOS 等）：开源免费+自带 Key+本地数据，Pagekin 的同级 但形态不同。

2. **与 Pagekin 重叠度最高**：**马良写作（SaaS）**、**FeelFish（桌面客户端闭源）**、**蛙蛙写作（SaaS）**。共性三件套为：设定档案 + 多级章节大纲 + 前 文上下文控制。差异点：足 Free（开源 GPL）/ 本地优先（SQLite）/ 模型不绑定（OpenAI 兼容+Gemini 原生）/可复用文风分析器 API —— 在国内商业竞品中，这五点几乎无一被同时满足。

3. **模型绑定向 vs. 模型中立项**：国内主流商业产品普遍平台自带模型（百度、达观、彩云、墨狐、星月）；开放"用户自带 Key"仅马良、FeelFish、灵犀等少数，与 Pagekin"不绑定模型"路线最接近。**开源生态（天命/AI-Novel-Writing-Assistant/InkOS）全部依赖自购 Key**，说明"模型中立+开源"在本地优先市场实具真实性需求。

4. **对标风险/机会点**：
   - 机会①：Pagekin 的 GPL 开源 + 本地优先 SQLite 是目前国内商业产品中近乎空白区（仅马良开源版可私有化部署，但主形态仍是 SaaS 订阅+积分）；
   - 机会②：模型中立（用户自有 Key）在国内闭源产品侧不被支持（除马良），开源侧已有共识但产品化不足；
   - 风险①：会员制产品低价（星月 9.9 元/10 万字、FeelFish $18/月起）可能压制 Pagekin 若未来出现商业模式的定价空间；
   - 风险②：蛙蛙被 OPPO 并购、百度作家平台功能迭代（App/App Store 免费档增强）均反映出"平台化投入"速度，本地优先路线需以"隐私/文件自由/版本历史/开源社区"作为差异化护城河。
