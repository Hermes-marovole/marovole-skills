@MrLarus 分享了用 Images 2.6 制作「真实玻璃 + 手绘线稿」混合视觉海报的四个案例，核心是将日常透明玻璃器皿放大到建筑或生活空间尺度，让折射、焦散和手绘小人一起进入画面：

| 序号 | 主题 | 透明核心物体 | 改造空间功能 | 中文主文案 | 英文旁注（原图实测） |
|---|---|---|---|---|---|
| 1 | **玻璃杯泳池** | 厚底透明圆柱玻璃水杯 | 微型露天泳池 | `今天 / 在一杯水里放空` | `Take a break in a glass of water.` |
| 2 | **香水瓶电梯** | 切面水晶玻璃香水瓶（含琥珀色香水液） | 微型透明观光电梯 | `今天 / 往透明里升一层` | `Going up, lightly.` |
| 3 | **玻璃球地铁站** | 实心透明水晶玻璃球 | 微型城市地铁站台 | `下一站 / 去轻一点的地方` | `Next stop: somewhere lighter.` |

### 2. 原帖完整结构化 Prompt 模板

来自评论区 Thread（`status/2119088491657330799`）：

```text
【透明核心物体】：{玻璃杯 / 香水瓶 / 花瓶 / 玻璃球 / 其他透明容器}
【空间功能】：{泳池 / 电梯 / 温室 / 地铁站 / 咖啡馆 / 阅读室等}
【手绘人物】：{人物数量、身份、动作与穿搭}
【内部元素】：{水 / 植物 / 家具 / 交通工具等}
【主文案】：{一句简短、有画面感的中文短句}
【画幅比例】：{默认 9:16}

创作一张「摄影级透明玻璃 × 手绘微型人物」虚实结合创意海报。

将【透明核心物体】放大到建筑或生活空间的尺度，并真正改造成【空间功能】。不要只是把小人放在物体旁边，而是让人物真实进入玻璃内部，并自然地使用这个空间。

透明物体必须保持明显的摄影级真实质感，包括真实玻璃厚度、边缘高光、反射、透光、折射、焦散、投影，以及不同曲面造成的局部放大、压缩和视觉偏移。

最重要的是让这些真实光学效果真正作用到手绘人物和内部空间上。例如人物经过玻璃观察时，腿部、身体或随身物品出现轻微折射变形；光线穿过玻璃后在地面、人物或内部设施上形成自然焦散，使人物真正存在于透明空间中，而不是简单贴在照片表面。

【手绘人物】保持明显二维绘本语言：黑灰铅笔线稿、少量彩铅或轻水彩、简洁五官、修长成年人体比例。人物动作自然生活化，可以阅读、候车、游泳、喝咖啡、乘电梯或休息，不看镜头，不摆模特姿势。

人物、家具、交通工具等内部元素可以保持手绘或轻半写实，而透明玻璃、水、植物等核心材质保持更强摄影感，形成“一半像真实摄影，一半像手绘绘本”的视觉碰撞。

环境保持极简，大面积使用暖奶油白、浅米色纸张或干净生活空间作为背景，只保留与主题有关的少量元素。不要构建复杂房间、城市或商业场景。

构图采用「巨大透明主体 + 微型人物 + 大留白」：

核心玻璃物体占据主要视觉面积，人物相对较小，通过明显尺度反差增强视觉惊喜；缩略图状态下也应该能第一眼看懂“这个透明物体被改造成了什么空间”。

在留白区域加入【主文案】，使用自然、不完全规整的中文手写字体，像日记、手账或独立绘本中的题字。可加入一句很小的英文旁注，但不要堆放大量文字。

整体光线使用柔和自然光，充分表现透明材质的折射、反射、焦散和透光，同时保持画面清爽、温暖、有生活感和编辑海报感。

最终效果应该让观众第一眼看到一个摄影质感很强的真实透明物体，第二眼才发现里面竟然生活着一群手绘小人，并进一步注意到玻璃折射、光影和人物之间真实的物理互动。
```

### 3. 引用链演进对比（1.0 → 2.0 → 3.0）

顺着原帖引用链回溯，可以看到这套「虚实混合海报」是怎么一步步迭代出来的：

1. **1.0 写实物体进入手绘日常（2026-11-02，`status/2117283999479706099`）**
   - 代表作：月光柔洗、月亮便利店、月亮唱片、月亮窗边。
   - 机制：把发光的写实月亮放进手绘日常场景，反差来自「超现实天体 × 日常生活场景」。
2. **2.0 写实花朵功能错位（2026-11-03，`status/2117636974672810334`）**
   - 代表作：雏菊雨伞（借一朵花回家）、郁金香沙发（坐进春天里）、马蹄莲台灯（今晚开一盏花）、牡丹花床（睡进一朵花里）。
   - 机制：引入**「功能错位」**变量——摄影级花朵直接作为二维手绘人物的雨伞、沙发、台灯、床铺，解决虚实两层元素的互动关系。
3. **3.0 透明玻璃容器 × 光学物理互动（2026-11-07，本帖 `status/2119088172433109353`）**
   - 代表作：玻璃杯泳池、香水瓶电梯、玻璃球地铁站、玻璃花瓶温室。
   - 机制：从「外部接触」升级为**「内部空间改造 + 跨维度光学作用」**——手绘人物进入摄影级玻璃内部，受真实玻璃折射变形与焦散光斑覆盖，消除了贴图感。
