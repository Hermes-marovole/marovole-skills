## Part 0: 个人 IP 原则与 Slogan（2026-11-08 用户拍板，最高优先级）

> **不用学写代码，学会像产品经理一样指挥 AI。**

- **身份**：AI 驾驭者（vibe coding 只当进阶系列名或身份标签用，不进主张句；首次出现要用大白话解释）。
- **人群**：不会写代码的职场人，即 FDE 日常在带的非技术同事。
- **方法（产品思维 + 程序思维的大白话版，每期内容的骨架）**：
  1. **说清需求**：要什么、给谁用、做到什么程度算好。
  2. **拆成步骤**：大事拆成 AI 能一步步干完的小事。
  3. **验收结果**：AI 交的活怎么检查、哪里不能信。
- **边界**：不用懂代码，但要懂怎么指挥（幻觉、遗忘这些边界必须讲）。不喊「100 倍」这类无依据的倍数，只用每期实测的耗时和费用。不靠贬低某类人制造对立。

- **配比**：七成方法 + 演示（拉新），两成 FDE 现场（立人设），一成立场观点片。
- **文章**：同样以「说清需求、拆成步骤、验收结果」为论证主线，结尾回到 slogan。

- ❌ **反对「网页对话框崇拜（Ask-an-LLM 幻觉）」**：把 AI 当许愿池，指望靠一句“神级提示词”在聊天框里解决复杂工作。真正的生产力在聊天框外面（文件系统、版本控制、工具闭环）。
- ❌ **反对「无门禁的 Vibe Coding / 无限垃圾生成（Infinite Slop）」**：没有 Grounding（事实溯源）和 Verifier（独立验收门禁）的 AI 自动生成，只是在以 10 倍速制造技术债和内容垃圾。
- ❌ **反对「只看跑分榜一，不看 $/task 与长程通关率」**：单步跑分 90% 的模型，在连续 10 步真实工作流里可能 80% 崩溃且一半在谎报完工。先改工作流、加熔断门，再谈换模型。
- ❌ **反对「把核心资产锁死在初创公司的漂亮云端壳子里」**：Wrapper 随时会被大厂收购并在 15 天内删库关停；只有纯文本躺在自己本地/Git 仓库里的 Prompts、Skills 和数据才是真资产。

### 6. 为什么是现在（Why It Matters Right Now）

- 在这个节点，普通人与普通企业破局的关键，不再是“学怎么写代码或背提示词”，而是**学会搭建自己的「验收台」与「可复用 Skill 资产」**。

## Part 2: 经验证的高光内容配方（Proven Content Recipes）

从已跑通的高质量长文与视频中提炼出的 4 种高转化结构：

1. **【FDE 降维翻译体】**（代表作：《你天天用 Codex，却没给它装「撤销键」》）
   - **钩子**：一个白领每天都在经历的崩溃瞬间（让 Agent 改表/改文档，一处改坏全盘皆输，没有「昨天的版本」）。
   - **破障**：引用官方文档证明「这工具不是给程序员专利，官方明说不用会写代码」。
   - **概念重命名**：把 3–4 个硬核工程原语翻译成直觉大白话（Repo=项目文件夹，Commit=手动存档点，Branch=平行副本，PR=交作业验收单）+ 极简代码生成动画示意。
   - **最小闭环练习**：5 步网页端无痛实操。
   - **克制收尾**：给出 3 条边界判断（什么该上、什么不该折腾），停在具体建议上，绝不喊口号。

2. **【多源对账深潜体】**（代表作：《补丁公开之后的 48 小时：拒绝率回答不了补丁窗口》）
   - **钩子**：把同一周看似矛盾的两条硬新闻并置（一边是厂商吹嘘 96.6% 恶意请求拒绝率，一边是研究者用开放模型 12 小时打穿浏览器补丁窗口）。
   - **证据对撞**：列出双方的实验条件、算力账单（如 $1,000/次 vs $100,000 无果）与原话。
   - **三层拆解**：① 为什么指标答非所问 → ② 为什么这是结构性问题而非单点漏洞 → ③ 为什么常规解法（如自动更新）存在反向风险旋钮。
   - **诚实留白（签名动作）**：专门留一节「我还没想清楚的地方」，坦陈当前证据无法下结论的边界，建立极高的专业信任感。

3. **【公开工作流重构体（Public Teardown）】**（新增主推栏目，吸收自 Dan Koe "Permissionless Apprentice"）
   - **钩子**：「如果我是 [某类传统岗位/某具体公司角色]，我今天会直接砍掉他们 80% 的手工操作。」
   - **旧世界切片**：还原该岗位真实的糟糕一天（打开 5 个软件、复制粘贴 3 小时、月底对账眼花）。
   - **新世界重构**：展示一套用 `Claude Code / Codex + 专属 Skill + 验证门禁` 搭好的 3 步流水线，附上真实耗时与单次 Token 成本（如 $0.15/次）。
   - **交付物钩子**：直接放出一份可复用的配置清单或流程图，自然衔接开源 Skill 库与企业内训需求。

4. **【60-85s 深蓝硬数字反转体】**（短视频主线）
   - **前 3 秒**：反常识硬数字直接砸脸（限 1 年内新研究或当季最新模型，如「单步得分 56.8% 的顶级 AI，连走十步及格率暴跌到 18.5%，而且一半在骗你」）。
   - **中段拆解**：实验怎么做的 → 对照组差在哪 → 为什么直觉是错的。
   - **落点**：给一个今天就能改的具体动作。
