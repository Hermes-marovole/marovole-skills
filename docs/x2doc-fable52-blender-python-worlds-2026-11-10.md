## 二、本机 Blender 5.2.3 LTS 复现与三轮「渲染—看图—修代码」实测记录

为了验证这套「纯 Python 驱动无头 Blender（Headless `bpy`）+ 视觉自检迭代」工作流在本地硬件上的真实表现与常见坑点，我们在 Apple M2 Max（64GB 内存）本机使用 **Blender 5.2.3 LTS**（build hash `e13b728c6880`），完全不下载任何外部 3D 模型或贴图，纯靠一段 Python 脚本（`build_dino_world.py`，369 行，调用 `bpy`、`bmesh`、`mathutils`）复现了同款「史前河岸双恐龙焦点转移 + 翼龙俯冲」的 3 秒（72 帧，24fps，分辨率 `1280x536`，渲染引擎 `BLENDER_EEVEE`，采样 48）微缩世界。

全过程跑了 **3 轮「写代码 → 抽帧渲染 → 视觉看图挑刺 → 改代码重跑」** 的真实迭代：

### 1. 第一轮（Pass 1）：踩中 3 个典型「盲写代码」大坑

第一轮脚本直接尝试操作 `obj_anim.animation_data.action.fcurves` 设置第 44 帧切镜插值，并在 `build_lofted_tube` 函数中沿样条曲线放样生成恐龙躯干、剑龙背板和翼龙翅膀。

- **报错 1（Blender 5.x Slotted Actions API 破坏性变更）**：
  无头运行 `/Applications/Blender.app/Contents/MacOS/Blender -b -P build_dino_world.py` 时当场抛出异常：
  `AttributeError: 'Action' object has no attribute 'fcurves'`。
  原因是 Blender 5.x 引入了分层动作槽（Slotted Actions），旧版直接读 `action.fcurves` 的代码会报错。改为在每一整数帧（1..72）直接逐帧写入相机位置、焦距与对焦距离关键帧，44 帧到 45 帧天然形成 1 帧硬切，无需手动遍历 `fcurves`。
- **视觉自检发现的 2 个几何与构图缺陷**（抽出第 1、20、38、48、65 共 5 张测试帧拼成 `pass1_sheet.jpg` 检查，5 帧渲染耗时 `6.48s`）：
  1. **截面法向轴搞反（背板与翅膀变成纸片边）**：`build_lofted_tube` 计算截面正交基时，把水平宽度半径 `rw` 和垂直高度半径 `rh` 的方向与相机视角拧了 90 度——导致剑龙背上的骨板和翼龙的翅膀在侧面镜头里变成了「刀刃朝向镜头」的细线，看起来像几根牙签插在背上。
  2. **长焦取景出画（主体被裁切）**：第一镜用了 `75mm` 焦距且前景剑龙离相机太近（`(-1.8, -0.5, 0.15)`），导致左下方只拍到一团灰绿色的脖子和半条腿，背板全部在画幅左外侧；右上方远景肉食恐龙的头顶也被画幅上沿削掉了一半。

### 2. 第二轮（Pass 2）：修正相机站位与多色调 Voronoi 程序化皮肤，但背板朝向仍不对

第二轮将前景剑龙移至 `(-1.95, 2.6, 0.12)`，肉食恐龙移至 `(3.8, 17.5, 0.18)`，加入下颌张嘴造型、眼部上方红色角冠（`Theropod_Crest`）和双足交替奔跑动画，并将材质升级为 `ShaderNodeTexNoise` + `ShaderNodeTexVoronoi` + `ShaderNodeBump` 的双色斑驳凹凸皮肤材质。

- **耗时数据**：场景构建耗时 `0.49s`，共生成 `194` 个对象（其中 `185` 个网格对象，`19,097` 个多边形面，`23,385` 个顶点），5 张测试帧渲染耗时 `6.31s`（单帧 `1.261s`）。
- **视觉自检结果（`pass2_sheet.jpg`）**：远景肉食恐龙的完整头部、张开的嘴和红色眼冠已经清晰落入画面右侧三分之一处，奔跑姿态自然；但剑龙背板因为依然沿 `+Z` 轴做环形管道放样，从侧面看仍然是细尖刺而非宽阔的五边形骨板，翼龙翅膀也依然偏窄。

### 3. 第三轮（Pass 3）：改为显式五边形面片与翼膜网格，72 帧全量成片一次通过

第三轮不再用圆柱管道凑扁平器官，而是专门编写了两个显式拓扑生成函数：
1. `add_diamond_plate`：直接在 `X-Z` 纵向平面内按 5 个轮廓顶点（`(-0.36L, -0.05)`、`(-0.56L, 0.44H)`、`(+0.04L, 1.02H)`、`(+0.52L, 0.50H)`、`(+0.34L, -0.05)`）构建带双面厚度的五边形剑龙骨板网格，确保侧面正对镜头时呈现出饱满的橙褐色菱形骨板剪影。
2. 翼龙翼膜（Patagium）：按前缘翼骨（Leading-edge spar）与后缘翼膜（Trailing-edge membrane）的 4 组展向截面直接构建双面四边形网格，展弦比与扑翼弧度一眼可辨。
3. 镜头 1 焦距调为 `50mm`（光圈 `f/1.1`），第 1 到 44 帧对焦距离从前景剑龙（`9.0m`）平滑推移到远景肉食恐龙（`21.5m`）；第 45 到 72 帧硬切为 `28mm` 广角低机位（光圈 `f/4.5`），领头翼龙从河道上方朝镜头俯冲掠过。

- **Pass 3 全量渲染实测数据（72 帧完整序列）**：
  - **Blender 版本**：`5.2.3 LTS`（macOS Metal 后端，`BLENDER_EEVEE`，48 采样）
  - **场景规模**：`194` 个对象（`185` 个网格对象），`18,848` 个多边形面，`23,079` 个顶点（按 `01_Terrain_River`、`02_Procedural_Flora`、`03_Rigged_Dinosaurs`、`04_Atmosphere_Cameras` 四个集合分装）
  - **构建耗时**：`0.49` 秒（从空场景执行 Python 脚本生成全部地形、75 棵五层针叶树、95 簇芦苇、3 类绑定动画的史前生物、三点黄金时刻布光与双镜头关键帧）
  - **72 帧全量渲染耗时**：`53.7` 秒（平均每帧 `0.746` 秒）
  - **输出产物**：24fps MP4（`885 KB`）与内嵌公众号预览 GIF（`2.0 MB`）。
